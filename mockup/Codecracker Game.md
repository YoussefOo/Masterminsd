# Mockup: Spielfeld

![Spielfeld](Codecracker%20Game.svg)

Der Spieler wählt für jede der vier zunächst leeren Positionen eine Farbe. Solange der Code unvollständig ist, wird der
Button „Code bestätigen“ sichtbar deaktiviert dargestellt. Nach der Bestätigung ist die Eingabe für die aktuelle Runde
gesperrt. Die Codehistorie zeigt mehrere Runden und stellt das jeweilige Server-Feedback kompakt direkt neben dem Tipp
dar. Eine Legende erläutert beide Feedbackarten sowie das Verhalten bei Zeitablauf.
